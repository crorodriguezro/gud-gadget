Design ownership
----------------

The phone GUD kernel module now owns only physical root-port observation. On
GUD disconnect it retains the USB HCD, requires the affected xHCI root port to
be observed disconnected, then requires USB_PORT_STAT_CONNECTION to remain set
for 15 polls at 100 ms. It emits one KOBJ_CHANGE uevent containing:

  GUD_HOST_REATTACH=1
  GUD_ROOT_PORT=<port>

The monitor is cancelled by normal GUD re-enumeration and expires after 6000
polls (10 minutes). It cannot write the DWC3 role and has no retry path.

The phone-side mir-android2-platform-gud helper remains the sole owner of the
bounded device -> host transaction. It no longer treats power_supply PRESENT
or ordinary USB add/change events as reattach evidence. Only the tagged kernel
uevent can start its existing 1.5-second gate. GUD re-enumeration cancels a
pending transaction.
