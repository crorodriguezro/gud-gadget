# Focused validation

`/tmp/mir-android2-platform-gud-p02-build/bin/mir_unit_tests_xdisp.bin`
passed all 50 tests from 10 suites. This includes lifecycle transitions,
forced-stop classification, poison persistence, start failure, activation
timeout, duplicate activation, presenter accounting, pending cancellation,
and presentation failure.

The Android2 test binary was present but could not be run directly because
the host lacked `libboost_filesystem.so.1.83.0`; the Python validation tests
were not run because pytest is not installed. No source change was made for
either environment issue.

T05-D used `MIRGUD_T05_SAFE_STALL=1`. The hook permits the first frame and
then waits before the second `drmModeAtomicCommit`; it cannot create an
accepted USB transaction. It was built in the existing offline container,
deployed temporarily, exercised 3 times, and then restored to the original
binary with the environment unset.
